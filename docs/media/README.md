# Documentation media

These files illustrate the NotchLyrics interface in the project README.

| File | Purpose |
| --- | --- |
| `notchlyrics-demo.gif` | Inline, looping interaction preview |
| `notchlyrics-demo.mp4` | Full demo, without audio |
| `lyrics-panel.png` | Expanded lyric panel and integrated tools |
| `lyric-timing.png` | Compact lyric-timing editor |
| `floating-lyrics.png` | Always show lyrics beneath the idle notch |

The screenshots are copied unchanged from the supplied Publish Assets folder. The approximately 20-second screen recording is converted to a silent MP4 and an 800-pixel-wide, 10 fps GIF for documentation. The original recording is not included.
